Network Design Packager

Swaps the built-in vector symbols for official artwork. Point it at the assets folder that came with this repository, choose your design, and it writes one self-contained file with the real images inside. Everything outside the two artwork blocks is copied through byte for byte.

1Choose the artwork folder

Pick the assets folder from this repository — it holds icons/cisco-pms3015 and rack-assets. Your browser asks permission to read it; nothing is uploaded. You can also add your own images: drop loose .jpg or .png files here, or keep them in the folder alongside the official ones.

2Choose your design file

Any compliant .edit.html — a starter kit, the blank template, or a file you made with the AI helper. Drop a .portable.html here instead and its editable source is recovered first. The file is never executed by this page.

    The invariant

    • Designs may differ completely; the v2 contract, the protected block markers, and asset:cisco/… / asset:rack/… identifiers may not.
    • The packager alters only NETWORK-ASSET-VAULT and EDITABLE-SOURCE-CAPSULE. It proves that afterwards by comparing every other byte.
    • Your own artwork is matched by exact filename: a design asking for asset:cisco/acme-switch.jpg uses your acme-switch.jpg. Names are case-sensitive.
    • Uploaded HTML may contain its own JavaScript. Package only designs you trust; this page never runs them, but whoever opens the result will.
    No upload, server, CDN, framework, or external runtime · the full editable source is preserved inside the result · image bytes are checked against their own signature and checksum before embedding.
