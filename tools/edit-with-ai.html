Edit a network design with AI

Builds the prompt for you, checks what the AI sends back, and writes a new file. Your file never leaves this browser, and everything outside the diagram data is copied through untouched, byte for byte.

1Choose your design file

Pick the .edit.html file you want to change. If you have not made one yet, use starters/network-design-template.edit.html.

No file chosen

2Say what you want changed

Describe the change in plain English, then copy the prompt and paste it into your AI chat. The prompt already contains your current diagram, so you do not need to attach anything.

Starting fresh — from a diagram, or a blank page?

Two prompts, both built for you. Works with the blank template — or with any design you already made: load your last file above and your branding, style and conventions carry over into the new document automatically.

A — Have your AI read your diagram first. Copy this into a new AI chat, attach your picture, send it, then correct anything it got wrong. Keep that chat open.

B — Three questions, all optional. Leave any of them empty and the AI derives the answer from your diagram. Then press Fill in the request, Copy prompt, and paste into that same chat.

Your branding — no AI involved

The brand is the one part the AI is never allowed to touch, so this panel edits it directly — same checks, same byte-exact save. Empty fields keep what the file already has.

Which part is changing?

A free AI model has a limit on how much it can write in one reply. Pick the smallest part that covers your change: it only has to send that part back, so there is less to run out of room on and less it can break by accident.

3Paste what the AI sent back

Paste the whole reply. Code fences, a stray sentence, or a trailing comma are fine — they get cleaned up automatically.

    4Save your new file

    Everything outside the diagram data is copied through unchanged. Save it, then double-click it to see your change.

    Next — want the official Cisco artwork version of this file? Open the packager, point it at the repository's assets folder, and choose the file you just saved. Your editable file stays as it is; the packaged copy is a second, portable deliverable.

    Nothing is uploaded. No server, CDN, or network connection is used. This page never parses your file as HTML, which is what keeps the drawing code and symbols identical to the ones you started with.
