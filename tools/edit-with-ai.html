Network Design HTML · Offline · No install

Edit a network design with AI

Builds the prompt for you, checks what the AI sends back, and writes a new file. Your file never leaves this browser, and everything outside the diagram data is copied through untouched, byte for byte.

1Choose your design file

Pick the .edit.html file you want to change. If you have not made one yet, use templates/network-design-template.edit.html.

No file chosen

2Say what you want changed

Describe the change in plain English, then copy the prompt and paste it into your AI chat. The prompt already contains your current diagram, so you do not need to attach anything.

Show the diagram data being sent

3Paste what the AI sent back

Paste the whole reply. Code fences, a stray sentence, or a trailing comma are fine — they get cleaned up automatically.

    4Save your new file

    Everything outside the diagram data is copied through unchanged. Save it, then double-click it to see your change.

    Nothing is uploaded. No server, CDN, or network connection is used. This page never parses your file as HTML, which is what keeps the drawing code and symbols identical to the ones you started with.
